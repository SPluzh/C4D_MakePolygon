# C4D_MakePolygon

**C4D_MakePolygon** — плагин для Cinema 4D (C++), реализующий функционал создания полигонов и закрытия отверстий по аналогии с клавишей **`P`** в Foundry Modo (**Make Polygon / Fill Hole**).

## Возможности (Features)

1. **Режим точек (Point Mode):**
   * **3 точки:** создание треугольника (`CPolygon`).
   * **4 точки:** создание четырёхугольника (`CPolygon`) с автоматической циклической сортировкой вершин вокруг центроида (предотвращает появление самопересекающихся полигонов / "бабочек").
   * **5+ точек:** создание N-угольника (N-Gon) через Maxon Modeling Engine с сохранением UVW и карт вершин.
   * **Согласование нормалей:** автоматическое определение правильного направления обхода (Manifold winding order) по соседним граням либо выравнивание в сторону камеры.

2. **Режим рёбер (Edge Mode):**
   * **1 ребро на границе:** автоматическая трассировка граничного контура (Boundary Loop Walker) и мгновенное закрытие отверстия (**Fill Hole**).
   * **2 ребра (фирменный режим Modo 14+):**
     * Если 2 ребра сходятся в углу — замыкание угла в Quad (если найдена 4-я вершина) или в Triangle.
     * Если 2 несвязанных/параллельных ребра на границе — создание Quad-моста между ними с оптимальным выбором диагоналей.
   * **3+ рёбер:** построение грани по замкнутому контуру выбранных рёбер.

3. **Интеграция:**
   * Полная поддержка **Undo / Redo** (`doc->StartUndo()`, `doc->AddUndo()`).
   * Автоматическое выделение вновь созданного полигона.
   * Совместимость с Cinema 4D 2025 и 2026.

## Назначение горячей клавиши `P` в Cinema 4D

1. Откройте **Window -> Customization -> Customize Commands...** (или `Shift + F12`).
2. В строке поиска введите: `Make Polygon (Modo P)`.
3. В поле **Shortcut** нажмите клавишу **`P`** (или любое удобное сочетание).
4. Нажмите **Assign**.
